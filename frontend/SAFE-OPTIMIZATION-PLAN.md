## 💡 經驗教訓

### ✅ 成功經驗
1. **漸進式部署**：一次一個優化
2. **本地驗證**：preview 測試是必須的
3. **快速回滾**：發現問題立即回滾
4. **分支測試**：使用 feature branch 而非直接修改 main

### ❌ 避免的錯誤
1. **一次性大規模修改**：導致難以定位問題
2. **跳過本地測試**：直接部署到生產環境
3. **忽略建置差異**：dev 正常不代表 prod 正常
4. **沒有回滾計劃**：問題發生時手忙腳亂
