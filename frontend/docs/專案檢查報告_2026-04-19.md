## ⚠️ 需要改進的地方

### 1. 程式碼組織 (中優先級)

**問題：views.py 過大 (3220 行)**
```
backend/api/views.py - 3220 行
包含 50+ 個 View classes
```

**建議改進：**
```python
# 拆分成模塊化結構
backend/api/views/
├── __init__.py
├── auth.py          # 認證相關 Views
├── notes.py         # 日記相關 Views
├── counselors.py    # 諮詢師相關 Views
├── health.py        # 健康數據 Views
├── ai.py            # AI 功能 Views
└── admin.py         # 管理功能 Views
```

**問題：前端 Console.log 殘留**
- 找到 **43 個** console.log/console.error
- 分佈於 12 個檔案

**建議改進：**
```javascript
// 建立統一的 logger 工具
// frontend/src/utils/logger.js
export const logger = {
  log: (...args) => {
    if (import.meta.env.DEV) console.log(...args)
  },
  error: (...args) => {
    console.error(...args)
    // 生產環境送到 Sentry
  }
}
```

### 2. Build 警告 (低優先級)

**Vite Build 警告：動態導入問題**
```
tokenStorage.js is dynamically imported but also statically imported
axios.js is dynamically imported but also statically imported
auth.js is dynamically imported but also statically imported
```

**影響：** 不會影響功能，但會略微增大 bundle
**建議：** 統一使用靜態導入或動態導入
