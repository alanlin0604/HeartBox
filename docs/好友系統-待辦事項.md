### 🟡 優先級 2：建議完成

#### 4. 導航通知徽章
**檔案**: `frontend/src/components/Layout.jsx`

**需要做的事情**:
```jsx
// 1. 引入 API
import { getReceivedRequests } from '../api/friends'

// 2. 加入狀態
const [unreadRequests, setUnreadRequests] = useState(0)

// 3. 載入未讀數量
useEffect(() => {
  const loadUnread = async () => {
    try {
      const res = await getReceivedRequests()
      const pending = res.data.results.filter(r => r.status === 'pending')
      setUnreadRequests(pending.length)
    } catch (error) {
      console.error('Failed to load unread requests:', error)
    }
  }
  loadUnread()
  // 可選：設定定期更新（每 60 秒）
  const interval = setInterval(loadUnread, 60000)
  return () => clearInterval(interval)
}, [])

// 4. 在好友連結上顯示徽章
// 找到好友的 NavLink，加入相對定位和徽章
<NavLink to="/friends" className="relative">
  <img src={link.icon} alt="" />
  {link.label}
  {link.to === '/friends' && unreadRequests > 0 && (
    <span className="absolute -top-1 -right-1 bg-red-500 text-white text-xs rounded-full w-5 h-5 flex items-center justify-center font-semibold">
      {unreadRequests > 9 ? '9+' : unreadRequests}
    </span>
  )}
</NavLink>
```

**預估時間**: 30 分鐘

## 📝 測試腳本範例

### 建立測試帳號
```bash
# 帳號 1
Username: test_user_a
Email: test_a@example.com
Password: testpass123

# 帳號 2
Username: test_user_b
Email: test_b@example.com
Password: testpass123
```

### 測試流程
1. **發送好友請求**
   - 用 A 帳號登入
   - 前往好友頁面
   - 點擊「搜尋用戶」
   - 搜尋 `test_user_b`
   - 發送好友請求（可選填訊息）

2. **接受好友請求**
   - 登出 A 帳號
   - 用 B 帳號登入
   - 前往好友頁面
   - 點擊「好友請求」
   - 看到 A 的請求
   - 點擊「接受」

3. **分享日記**
   - 用 A 帳號登入
   - 寫一篇新日記（或使用現有日記）
   - 點擊「分享給好友」按鈕
   - 選擇 B 用戶
   - 確認分享

4. **查看分享**
   - 登出 A 帳號
   - 用 B 帳號登入
   - 前往好友頁面 > 「好友分享」Tab
   - 看到 A 分享的日記
   - 點擊查看完整內容

5. **留言**
   - 在詳情頁面底部輸入留言
   - 點擊「新增留言」
   - 確認留言顯示

6. **查看動態**
   - 用 A 帳號登入
   - 寫一篇新日記（觸發動態）
   - 登出 A 帳號
   - 用 B 帳號登入
   - 前往好友頁面 > 「好友動態」Tab
   - 看到 A 的新日記動態
