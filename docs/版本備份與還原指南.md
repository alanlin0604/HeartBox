## 還原方式

### 方法一：切換到備份版本（僅查看，不修改）

```bash
git checkout v1.0-pre-capacitor
```

> 這會進入 detached HEAD 狀態，適合查看或測試舊版本。
> 要回到最新版本，執行 `git checkout main`。

### 方法二：從備份版本建立新分支（推薦用於修復）

```bash
git checkout -b 修復分支名稱 v1.0-pre-capacitor
```

> 從備份點建立一條新分支，可以在上面開發或修復，不影響 main。

### 方法三：將 main 完全回退到備份版本（危險操作）

```bash
# 確保所有變更已 commit 或 stash
git stash

# 回退 main 到備份版本
git checkout main
git reset --hard v1.0-pre-capacitor

# 強制推送到遠端（會覆蓋遠端歷史，務必確認）
git push origin main --force
```

> **警告：** 此操作會丟失備份點之後的所有 commit，且無法輕易復原。僅在確定要放棄所有新變更時使用。

## 其他常用指令

```bash
# 查看所有 tag
git tag -l

# 查看此 tag 的詳細資訊
git show v1.0-pre-capacitor

# 比較目前版本與備份版本的差異
git diff v1.0-pre-capacitor..HEAD

# 查看備份版本之後的所有 commit
git log v1.0-pre-capacitor..HEAD --oneline
```
