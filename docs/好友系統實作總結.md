## 權限與安全

### 權限檢查矩陣

| 操作 | 權限要求 |
|------|---------|
| 搜尋用戶 | 任何登入用戶 |
| 發送請求 | 不能發給自己、不能重複發送 |
| 接受/拒絕請求 | 只能操作發給自己的請求 |
| 解除好友 | 必須是好友關係 |
| 分享日記 | 只能分享自己的日記給好友 |
| 查看分享 | 只能查看分享給自己的或自己分享的 |
| 留言 | 只能留言在分享給自己的日記上 |
| 刪除留言 | 只能刪除自己的留言 |

### 資料保護

- 日記內容保持加密（使用 MoodNote 的加密機制）
- 留言內容明文儲存（便於顯示和搜尋）
- 分享記錄使用 `unique_together` 防止重複
- 級聯刪除確保資料一致性

## API 使用範例

### 發送好友請求
```bash
curl -X POST http://localhost:8000/api/friends/requests/ \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"to_user_id": 5, "message": "想跟你成為好友！"}'
```

### 分享日記給好友
```bash
curl -X POST http://localhost:8000/api/friends/share-note/ \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"note_id": 10, "friend_ids": [5, 7]}'
```

### 對分享日記留言
```bash
curl -X POST http://localhost:8000/api/friends/share/1/comment/ \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"content": "加油！繼續保持！"}'
```
