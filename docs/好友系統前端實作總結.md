# 好友系統前端實作總結

## 完成日期
2026-04-19

## 實作概述
已完成 HeartBox 好友系統的完整前端 UI，包含所有 17 個後端 API 的整合。

---

## 新增文件列表

### 1. API Client
**檔案**: `frontend/src/api/friends.js`
- 包含所有 17 個 API 端點的函數
- 實作快取機制（使用現有的 cache.js）
- 好友管理、日記分享、留言、動態等功能

### 2. 主頁面
**檔案**: `frontend/src/pages/FriendsPage.jsx`
- Tab 導航系統（好友列表、收到的分享、好友動態）
- 使用 glass 樣式設計
- 完整的響應式設計

### 3. 好友管理元件

#### FriendsList.jsx
`frontend/src/components/friends/FriendsList.jsx`
- 顯示好友列表（2列網格）
- 好友卡片包含：頭像、用戶名、連續天數、總日記數、好友時長
- 解除好友功能（帶確認對話框）
- Empty state 處理

#### FriendSearch.jsx
`frontend/src/components/friends/FriendSearch.jsx`
- Modal 搜尋介面
- 即時搜尋（debounce 500ms）
- 顯示搜尋結果與狀態（已是好友/已發送請求/可發送）
- 發送好友請求時可附加訊息

#### FriendRequests.jsx
`frontend/src/components/friends/FriendRequests.jsx`
- Modal 介面，兩個 Tab（收到的請求 / 發送的請求）
- 接受/拒絕好友請求
- 顯示請求狀態（pending/accepted/rejected）

### 4. 日記分享元件

#### SharedWithMe.jsx
`frontend/src/components/friends/SharedWithMe.jsx`
- 顯示好友分享的日記列表（2列網格）
- 卡片包含：分享者、時間、情緒條、內容預覽、留言數
- 分頁載入
- 點擊查看詳情

#### SharedNoteDetail.jsx
`frontend/src/components/friends/SharedNoteDetail.jsx`
- Modal 顯示完整日記內容
- 包含：分享者資訊、日期、情緒分數、標籤
- 整合 CommentSection 元件

#### CommentSection.jsx
`frontend/src/components/friends/CommentSection.jsx`
- 顯示所有留言（含頭像、用戶名、內容、時間）
- 新增留言表單
- 刪除自己的留言（帶確認）

#### ShareNoteToFriends.jsx
`frontend/src/components/friends/ShareNoteToFriends.jsx`
- Modal 選擇好友分享日記
- Checkbox 多選好友
- 顯示已分享狀態
- 確認分享

### 5. 好友動態元件

#### FriendsActivity.jsx
`frontend/src/components/friends/FriendsActivity.jsx`
- 時間軸樣式顯示好友活動
- 時間篩選（24h/48h/3d/1週）
- 活動類型：新日記、連續記錄更新
- Icon 與描述文字

### 待整合項目

#### 1. 日記卡片分享按鈕
需要修改 `NoteCard.jsx` 或 `NoteDetailPage.jsx`：
```jsx
import ShareNoteToFriends from './friends/ShareNoteToFriends'

// 在元件中加入
const [showShareModal, setShowShareModal] = useState(false)

// 按鈕
<button onClick={() => setShowShareModal(true)}>
  <ShareIcon /> 分享給好友
</button>

// Modal
{showShareModal && (
  <ShareNoteToFriends
    noteId={note.id}
    onClose={() => setShowShareModal(false)}
  />
)}
```

#### 2. 導航通知徽章
需要在 `Layout.jsx` 或 `NotificationBell.jsx` 中顯示未讀好友請求數：
```jsx
const [unreadRequests, setUnreadRequests] = useState(0)

// 載入未讀數量
useEffect(() => {
  const loadUnread = async () => {
    const res = await getReceivedRequests()
    setUnreadRequests(res.data.results.filter(r => r.status === 'pending').length)
  }
  loadUnread()
}, [])

// 在好友連結上顯示徽章
{unreadRequests > 0 && (
  <span className="badge">{unreadRequests}</span>
)}
```

## 效能考量

### 已實作的優化
1. **Lazy Loading**: 所有頁面和大型元件都使用 lazy loading
2. **快取機制**: API 回應使用快取（30-60秒）
3. **Debounce**: 搜尋輸入使用 debounce（500ms）
4. **分頁載入**: SharedWithMe 使用分頁，避免一次載入過多資料

### 未來優化建議
1. **虛擬滾動**: 如果好友列表/動態列表過長，可使用 react-window
2. **圖片懶載入**: 好友頭像使用 lazy loading
3. **骨架屏**: 使用 Skeleton 元件代替 LoadingSpinner

## API 端點對應表

| 功能 | 前端函數 | 後端 API | 元件 |
|------|---------|----------|------|
| 取得好友列表 | `getFriends()` | `GET /api/friends/` | FriendsList |
| 搜尋用戶 | `searchUsers(query)` | `POST /api/friends/search/` | FriendSearch |
| 發送好友請求 | `sendFriendRequest(userId, msg)` | `POST /api/friends/requests/` | FriendSearch |
| 收到的請求 | `getReceivedRequests()` | `GET /api/friends/requests/received/` | FriendRequests |
| 發送的請求 | `getSentRequests()` | `GET /api/friends/requests/sent/` | FriendRequests |
| 接受請求 | `acceptFriendRequest(id)` | `POST /api/friends/requests/{id}/accept/` | FriendRequests |
| 拒絕請求 | `rejectFriendRequest(id)` | `POST /api/friends/requests/{id}/reject/` | FriendRequests |
| 解除好友 | `removeFriend(friendId)` | `DELETE /api/friends/{friend_id}/` | FriendsList |
| 分享日記 | `shareNoteWithFriends(noteId, friendIds)` | `POST /api/friends/share-note/` | ShareNoteToFriends |
| 撤銷分享 | `revokeShare(shareId)` | `DELETE /api/friends/share/{share_id}/` | (未使用) |
| 收到的分享 | `getSharedWithMe(page)` | `GET /api/friends/shared-with-me/` | SharedWithMe |
| 我的分享 | `getSharedByMe(page)` | `GET /api/friends/shared-by-me/` | ShareNoteToFriends |
| 分享詳情 | `getSharedNoteDetail(shareId)` | `GET /api/friends/share/{pk}/detail/` | SharedNoteDetail |
| 新增留言 | `addComment(shareId, content)` | `POST /api/friends/share/{share_id}/comment/` | CommentSection |
| 取得留言 | `getComments(shareId)` | `GET /api/friends/share/{share_id}/comments/` | CommentSection |
| 刪除留言 | `deleteComment(commentId)` | `DELETE /api/friends/comment/{comment_id}/` | CommentSection |
| 好友動態 | `getFriendActivity(hours)` | `GET /api/friends/activity/` | FriendsActivity |
