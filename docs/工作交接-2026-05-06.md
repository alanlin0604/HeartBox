## 🚧 未完成的事

### 1. 登入轉圈很久（最高優先）

**根因：** Cloud Run `min-instances=0`，閒置 >15 分鐘後第一次登入冷啟動 ~30 秒。

**選項（按效果排序）：**

| 方案 | 動作 | 成本 | 效果 |
|------|------|------|------|
| A. min-instances=1 | `gcloud run services update heartbox-api --min-instances=1 --region=asia-east1 --project=heartbox-app` | $5–10 USD/月 | 永遠 1.5s 內 |
| B. 前端 pre-warm | LoginPage mount 時 fire 一個 ping 喚醒後端 | 免費 | 中等 |
| C. 合併 login+profile | 後端 LoginView 回傳一併帶 user 資料，省 1 次 roundtrip | 免費 | 省 ~150ms |
| D. UX 補強 | 請求 >3s 顯示「正在喚醒伺服器…」訊息 | 免費 | 不解決根因，但避免使用者以為當機 |

**我的建議：** 先做 B + C + D（零成本），仍嫌慢再上 A。

**起手點：**
- B 在 [LoginPage.jsx:42](frontend/src/pages/LoginPage.jsx#L42) 那個 `useEffect` 裡，加一行 `fetch('/api/').catch(() => {})` 喚醒
- C 改 [backend/api/views.py:327 LoginView](backend/api/views.py#L327)，回傳 dict 多塞 `user` 欄位（用 `UserProfileSerializer` 序列化）；前端 [AuthContext.jsx:51](frontend/src/context/AuthContext.jsx#L51) 直接從 login response 取 user，不再呼叫 getProfile
- D 在 LoginPage 用 setTimeout(3000) 後若 still loading 就 setError 一個提示

## 🔧 新電腦環境設定步驟

照這個順序做，全部跑完約 30–60 分鐘。

### A. 必裝（無這些跑不起來）

```powershell
# 1. Git（如果還沒裝）
winget install Git.Git

# 2. Node.js LTS（CI 用 22，本機用 22+ 即可）
winget install OpenJS.NodeJS.LTS

# 3. 重開 PowerShell 讓 PATH 生效，驗證
node -v   # 應顯示 v22.x 或更新
npm -v

# 4. Clone repo
cd C:\Users\<你的名字>\OneDrive\Desktop  # 或你慣用位置
git clone https://github.com/alanlin0604/HeartBox.git
cd HeartBox

# 5. 設 git user（如果是新機）
git config --global user.name "alanlin0604"
git config --global user.email "alan930604@gmail.com"
```

### B. 前端 dev 環境

```powershell
cd frontend
npm install                        # 第一次跑很久，約 3–5 分鐘
```

**建立 `frontend/.env`**（檔案不入 git）：
```
VITE_API_URL=https://api.heartbox.tw/api
VITE_GOOGLE_CLIENT_ID=
VITE_VAPID_PUBLIC_KEY=
VITE_SENTRY_DSN=
```

> Google 登入 / Push 通知 / Sentry 三個 secret 沒填的話對應功能會停用，但網站本身能跑。要完整功能找之前的備份。

```powershell
npm run dev                        # 啟動 vite dev server，預設 :5173
```

### C. 後端 dev 環境（如果要動 backend）

```powershell
# Python（CI 用 3.12）
winget install Python.Python.3.12

cd backend
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r ../requirements.txt
```

**建立 `backend/.env`** 需要：`DJANGO_SECRET_KEY`、`LLM_PROVIDER` / `LLM_SERVER_URL` / `LLM_SERVER_API_KEY`（Phase 0b 後 OpenAI 已下線；本地開發可設 `LLM_PROVIDER=mock`）、`ENCRYPTION_KEY`、`DATABASE_URL`、`EMAIL_*`。
（找之前的備份，這些是 secrets 不在 repo 裡。**2026-06 後此文件僅為歷史交接，最新環境變數請看 `backend/.env.render.example` 與 `docs/llm-runbook.md`。**）

```powershell
python manage.py migrate
daphne -b 0.0.0.0 -p 8000 moodnotes_pro.asgi:application
```

> 也可以直接連線上後端（`https://api.heartbox.tw`）開發，不一定要本機 backend。

### D. Android Studio（如果要繼續做 Android）

1. 裝 [Android Studio](https://developer.android.com/studio)（內建 JDK 21）
2. File → Open → 選 `HeartBox/frontend/android`（**不是** frontend 或 frontend/android/app）
3. Trust Project → 等 Gradle sync（第一次 5–15 分鐘）
4. 缺的 SDK / Build-Tools 一律 Install
5. 跑 emulator: 上方 device dropdown 選 AVD → 點 Run ▶

**Keystore（簽 release APK 用）：**
之前放在 `c:\Users\alan9\.heartbox-android\heartbox.keystore`，這個檔不在 repo，從你的雲端備份還原到新電腦同樣路徑。密碼也要找回。
