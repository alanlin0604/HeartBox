# 重要原則（請務必遵守）

✅ **純使用者視角**：寫使用者「看到 / 點 / 輸入 / 拍照 / 等 / 收到」的動作。
❌ **不要寫技術細節**：不要提 API、後端、LLM、加密、AI 演算法。
❌ **不要寫資料庫 / token / fallback 那種程式碼名詞**。

舉例：
- ❌ 不寫：「後端呼叫 TAIDE LLM 分析情緒」
- ✅ 寫：「等 10 秒，AI 自動補上心情分數跟一段暖心回饋」

- ❌ 不寫：「Cache miss 觸發並行 Open-Meteo API 呼叫」
- ✅ 寫：「畫面顯示今天的天氣 + 給你一段話」

評審大多是教授、業界主管，**他們想看的是『產品好不好用』，不是『程式怎麼寫』**。

# 專題簡介（給你 context）

**HeartBox 心事盒** — AI 心情日記網站
- 每天寫日記 → AI 自動分析心情 → 累積後給個人化建議
- 用網頁版 + iOS App

# 設計要求

- 風格：簡單乾淨，跟主圖一致
- 顏色：橘色 #F97316 標核心、紅色標警示、灰色為主
- 格式：每張一個 Mermaid 圖
- 比例：適合 16:9 投影片
- 文字：繁體中文
- **每張不超過 8 個節點**
- 每張先給「**標題 + 一句話說明**」再給 Mermaid 程式碼

# 我要的 12 張使用者操作流程

## 圖 A：第一次進網站要做什麼

**情境**：使用者朋友推薦這個 app，打開官網。

**使用者經歷**：
1. 打開 `heartbox.tw`
2. 看到 Logo + 一句話介紹「AI 陪你看見心情的規律」
3. 滾下去看 5 個功能特色卡片（智慧日記 / AI 對話 / 個人化洞察 / 呼吸練習 / 自我評估）
4. 想試試 → 點「免費註冊」按鈕
5. 已有帳號 → 點「登入」按鈕

**結果**：進入註冊頁或登入頁。

---

## 圖 B：第一次註冊帳號

**情境**：點了「免費註冊」按鈕。

**使用者經歷**：
1. 填使用者名稱 + 信箱 + 密碼
2. 選自己的年齡（18 歲以上 / 13-17 歲 / 13 歲以下）
3. 勾選同意服務條款跟隱私政策（4 個勾選框）
4. 按「註冊」
5. 看到「我們已寄驗證信到你的信箱」訊息
6. 打開信箱 → 找到驗證信 → 點裡面的連結
7. 看到「驗證成功，請登入」
8. 跳回登入頁，輸入剛剛的帳密 → 登入成功

**特殊狀況**：
- 13-17 歲 → 多一步填家長 email，家長同意後才能用
- 13 歲以下 → 顯示「未滿 13 歲無法註冊」，無法繼續

**結果**：第一次登入，跳到日誌主頁。

---

## 圖 C：寫第一篇日記

**情境**：剛登入，看到日誌主頁，想開始記錄心情。

**使用者經歷**：
1. 看到中間有個寫日記區塊
2. 上方有「今日書寫提示」(AI 建議的題目，例如「今天最開心的一件事？」) — 想用點「使用此提示」會自動填入
3. 在輸入框寫下今天的心情
4. （想拍照）點上傳圖片 → 從相簿選照片
5. （想標記）選今天做了什麼活動：運動 / 社交 / 工作 / 旅行 / ...
6. （想標記）選天氣（晴 / 雨）+ 氣溫
7. （想分類）輸入標籤，例如「#工作」「#感恩」
8. 按「儲存日誌」
9. 立刻看到日記出現在下方列表
10. 等 10-15 秒 → 日記自動補上「心情分數」「壓力指數」「一段 AI 暖心回饋」

**結果**：完成第一篇日記，看到 AI 給的回饋。

---

## 圖 D：看 AI 給我什麼樣的回饋

**情境**：寫完日記後，想看 AI 怎麼分析我的內容。

**使用者經歷**：
1. 點剛寫的那篇日記 → 進入日記詳情頁
2. 看到上方有「心情分數」彩色條（-1.0 紅色到 +1.0 綠色）
3. 看到「壓力指數」0-10 棒狀條
4. 看到「天氣 + 標籤 + 活動」小標籤
5. 往下看到「AI 暖心回饋」區塊
6. AI 寫了一段 80-150 字的話，例如：「親愛的朋友，看到你工作上遇到沮喪...我想給你幾點建議：1. 辨清自己的需求...」
7. 想刪除 → 右上「刪除」按鈕
8. 想編輯 → 右上「編輯」按鈕
9. 想釘選重要日記 → 右上 📌 按鈕

**結果**：理解 AI 怎麼解讀你的心情，學到一些情緒調適建議。

---

## 圖 E：每天打開 app 看「今日個人化建議」

**情境**：使用者連續用了一段時間，每天打開日誌頁面想看 AI 給的建議。

**使用者經歷**：
1. 打開日誌頁
2. 最上面看到一個橘色 card「今日個人化建議」
3. 顯示今天的天氣（例：「6月29日 · 晴朗 · 24°/30°C · 目前 27°C」）
4. 顯示一段暖心的話，例如：
   - 「今天是個陰天，你過去陰天心情通常比較低，可以開盞暖燈或泡杯熱飲幫自己提振一下精神」
   - 「明天是週末，你週末通常比較放鬆，不妨給自己安排一件喜歡的事」

**特色**：建議**結合了天氣 + 你長期的心情規律**。每個人看到的建議都不一樣。

**結果**：每天打開 app 都有一份「為你寫的話」，像有人在關心你。

---

## 圖 F：看自己長期的心情趨勢（Dashboard）

**情境**：用了 1-2 個月，想看看自己心情有什麼規律。

**使用者經歷**：
1. 點上方導覽「分析」→「心情週報/月報」
2. 看到四個大數字：連續記錄 X 天 / 本週平均心情 / 本月日記 N 篇 / 感恩紀錄 M 則
3. 滾下去看「心情趨勢」折線圖（過去 180 天每週的平均心情）
4. 看「心情 × 天氣」散布圖 → 知道自己晴天還是雨天心情比較好
5. 看「常用標籤排行」→ 知道自己最常記錄什麼主題
6. 看「個人化洞察」卡片 — 系統自動找出你的規律，例如：
   - 「你週末平均心情比平日好 0.21」
   - 「你 6 月是心情最低的月份」
   - 「雨天時你的平均壓力高 2.3 分」
7. 滾下去看月行事曆（每天一格，色階表示情緒好壞）
8. 看年度像素圖（GitHub 風格的 365 格）

**結果**：看到自己平常注意不到的心情規律。

---

## 圖 G：跟 AI 聊聊心事

**情境**：今天心情不太好，想找個對象傾訴但不想麻煩朋友。

**使用者經歷**：
1. 點上方導覽「社群」→「AI 聊天」
2. 看到對話歷史（沒用過的話顯示「+ 新對話」）
3. 點「+ 新對話」開新的聊天 session
4. 在底下輸入框寫：「最近壓力好大，工作做不完一直加班，覺得快撐不住了」
5. 按送出 → 看到自己的訊息出現
6. 等 5-15 秒 → AI 回覆出現
7. AI 回的話會：
   - 同理你的感受
   - 可能引用相關的心理知識（從專業文章）
   - 給具體的建議
8. 可繼續對話，AI 會記得前面說的內容
9. 對 AI 訊息覺得很有幫助 → 點 👍 / 不滿意 → 點 👎

**特色**：AI 結合了心理學專業文章，不只是普通聊天。

**結果**：感覺有人在聽你說話、給你建議。

---

## 圖 H：跟匿名社群分享心情

**情境**：心情低落，想看看別人怎麼度過類似的情境，不想暴露身份。

**使用者經歷**：
1. 點上方導覽「社群」→「匿名社群」
2. 看到貼文牆，可按類別篩選（紓壓 / 情感 / 工作 / 生活）
3. 看到別人的匿名貼文（顯示「匿名 #某數字」不顯示真實名字）
4. 想表達支持 → 點 ❤
5. 想留言 → 點貼文 → 寫留言 → 預設也是匿名
6. 想自己發一篇 → 點右下角「+ 發新貼文」
7. 寫內容 + 選類別 + 確認「匿名」是打勾的
8. 按送出 → 貼文出現在牆上
9. 不適合的內容 → 點「⋯ 檢舉」→ 選原因（垃圾 / 騷擾 / 自傷）→ 系統收到 → 管理員會審核

**結果**：在一個安全的社群中找到共鳴。

---

## 圖 I：填寫心理量表（PHQ-9 / GAD-7）

**情境**：想知道自己最近狀態是不是有點不對勁。

**使用者經歷**：
1. 點上方導覽「更多」→「自我評估」
2. 看到量表列表：
   - PHQ-9（憂鬱程度量表）
   - GAD-7（焦慮量表）
   - PSS-10（壓力量表）
   - ISI（失眠量表）
3. 點一個量表 → 看到 7-10 個題目
4. 每題用 0-4 分回答（從不 / 偶爾 / 一半時間 / 大部分 / 總是）
5. 全填完按「送出」
6. 看到結果頁：
   - 總分（例：8 / 27）
   - 解讀（輕度 / 中度 / 重度憂鬱）
   - 建議（如果分數高 → 建議找專業諮商師）
7. 想分享給諮商師 → 點「分享給諮商師」→ 選一位諮商師 → 對方就能看到結果

**結果**：客觀知道自己狀態，必要時找專業協助。

---

## 圖 J：呼吸練習放鬆 / 冥想

**情境**：壓力大、想冷靜下來、需要 5 分鐘暫停。

**使用者經歷**：
1. 點上方導覽「健康」→「呼吸與冥想」
2. 選練習類型：
   - 4-7-8 呼吸法（睡前用）
   - Box 呼吸法（4-4-4-4）
   - 深呼吸
3. 選時長：1 / 3 / 5 分鐘
4. 按開始
5. 螢幕中央顯示一個大圓圈
6. 圓圈動畫：吸氣時放大、屏住不動、吐氣時縮小
7. 中央顯示文字：「吸氣...4」「屏住...7」「吐氣...8」+ 倒數
8. 完成後顯示「練習完成」+ 統計（今天總共做了 X 分鐘）

**結果**：3-5 分鐘冷靜下來，可以回去工作或睡覺。

---

## 圖 K：跟好朋友互相打氣（朋友功能）

**情境**：想邀請最要好的朋友也用這個 app，互相鼓勵。

**使用者經歷**：
1. 點上方導覽「社群」→「好友」
2. 看到 3 個 tab：我的朋友 / 收到的邀請 / 探索朋友
3. 想加好友 → 輸入對方的使用者名稱 → 送出邀請
4. 對方收到通知 → 接受邀請 → 變成好友
5. 在「好友活動牆」看到朋友的活動：
   - 「@Alice 達成 30 天連續記錄 🔥」
   - 「@Bob 完成了 PHQ-9 量表」
6. 想關心朋友 → 進對方的個人頁（如果他開放） → 留言鼓勵
7. 朋友如果分享了某些內容給你 → 你會收到通知

**結果**：互相監督、互相鼓勵，養成寫日記的習慣。

---

## 圖 L：寫到負面內容時的安全保護

**情境**：使用者最近狀態很差，寫到「想結束生命」之類的字。

**使用者經歷**：
1. 在日記 / AI 對話 / 社群貼文中寫到危機字眼（「想死」「自殺」「結束生命」等）
2. 按送出
3. 系統偵測到 → 內容仍然儲存（不會擋你）
4. **整個畫面跳出橘紅色 banner**：
   > **「你並不孤單。這裡可以求助：」**
   > 📞 1995 - 生命線協會（24 小時）
   > 📞 1925 - 安心專線（24 小時）
   > 📞 113 - 婦幼保護專線
5. Banner 也提供：
   - 「聯絡專業諮商師」連結（跳到諮商師目錄）
   - 「我已經沒事了」按鈕（可關閉 banner）

**特色**：這個保護機制橫跨所有寫入功能（日記、AI 對話、社群），不論在哪都會觸發。

**結果**：使用者在危急時刻看到求助資源，不會孤立無援。

# 嚴格規則

- **每張圖 ≤ 8 個節點**（PPT 可讀性）
