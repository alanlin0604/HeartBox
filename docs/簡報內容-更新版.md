### 第 5 頁：專題動機 🔧
針對現有心理健康數位工具的不足，本專題歸納出以下**六大**問題點：

1. **功能碎片化與回饋淺層化**：市面應用多為簡單文字紀錄，缺乏深層情緒分析。
2. **AI 輔助潛力尚未開發**：鮮少應用結合專業知識庫，AI 回饋空洞。
3. **隱私資安風險高漲**：心理日記包含敏感個資，多數 APP 採明文儲存。
4. **整合性服務平台匱乏**：測驗量表、衛教資訊、諮商預約散落各處。
5. **跨文化與語言屏障**：優質工具常受限於單一語言。
6. 🆕 **行動端與健康數據脫節**：心理健康應用多為純網頁，缺乏與裝置健康數據（步數、心率、睡眠）的深度整合，無法對應「身心一體」的全面評估。

---

### 第 6 頁：專題目標 🔧

**AI 深度情緒洞察與智慧回饋系統**
- 自架 TAIDE-LX-7B-Chat（4-bit NF4 量化）分析情緒（-1～+1）與壓力指數（0～10），資料不離境
- LangChain retriever + ChromaDB + bge-m3 多語言 embedding，從心理學知識庫提取有理據的建議

**高規格加密日記保護機制**
- Fernet（AES-CBC + HMAC-SHA256）端對端加密
- Tiptap 富文本編輯器，支援圖片、語音

**多維度數據可視化與臨床分析**
- PHQ-9、GAD-7 國際標準量表
- 心情趨勢、壓力雷達、Year in Pixels、AI 每週摘要報告

**無國界多語言支持與即時諮商平台**
- i18n 三語切換（zh-TW / en / ja）
- WebSocket 即時通訊 + 預約管理

🆕 **跨平台原生行動 App**
- Capacitor 包裝為 Android 原生 App，準備上架 Google Play
- 整合 Health Connect / HealthKit 讀取步數、心率、HRV、睡眠等資料
- 將生理指標與情緒紀錄做關聯分析，實現「身心一體」評估

### 🆕 新增頁：Health Connect 健康資料整合

**標題：Health Connect / HealthKit 健康資料整合**

透過 `@capgo/capacitor-health` 統一抽象層，**同一份程式碼同時支援 Android 與 iOS**：

| 資料類型 | Android (Health Connect) | iOS (HealthKit) |
|---------|:---:|:---:|
| 步數 (Steps) | ✓ | ✓ |
| 心率 (Heart rate) | ✓ | ✓ |
| 心率變異 (HRV) | ✓ | ✓ |
| 主動消耗熱量 | ✓ | ✓ |
| 運動時長 | ✓（Workouts API） | ✓ |
| 睡眠（含分期） | ✓ | ✓ |

**同步策略：**
- **冷啟動同步**：App 開啟即觸發
- **前景恢復同步**：監聽 `App.appStateChange`，回到前景自動同步
- **30 分鐘節流**：避免重複呼叫
- **權限分層**：使用者可隨時於系統設定撤銷授權

> 圖：放健康儀表板截圖（如有），或 Health Connect 授權對話框

### 🆕 新增頁：隱私保護與健康資料揭露

**標題：隱私保護機制**

**多層加密體系：**
- 日記內容：Fernet（AES-CBC + HMAC-SHA256）端對端加密
- 認證令牌：JWT + Refresh Token，支援兩步驟驗證（2FA）
- 傳輸安全：HTTPS（Cloudflare TLS）+ CORS 嚴格白名單

**Google Play 健康資料合規：**
- 隱私政策第 7 章專門揭露 Health Connect 讀取的所有資料類型
- 明確聲明：**不分享給第三方、不用於 AI 訓練、僅在用戶帳號內處理**
- Settings 頁面加入「法律資訊」區塊，含 隱私政策 / 健康資料政策 / 服務條款 三個直連連結
- 通過 Google Play 健康應用宣告（Health Apps Declaration）審查需求

> 圖：放 Settings 頁面的法律資訊 section，或 Privacy 頁面的 s7 健康資料章節

### 🆕 新增頁：CI/CD 自動化部署與 Play Store 上架

**標題：自動化部署與行動端發布管線**

**前端 / 後端持續部署：**
- `git push main` → GitHub Actions 自動跑後端 Django 測試 + 前端 Vite build
- 測試通過 → wrangler-action 部署至 Cloudflare Pages（heartbox.tw）
- 後端透過 Google Cloud Run 自動 scale

**行動端 APK 建置管線：**
- Mobile Build workflow（手動觸發）：Web build → Capacitor sync → Android Gradle assembleRelease
- Keystore 透過 GitHub Secrets 安全管理
- 產出已簽章的 release APK / AAB，**直接可上 Play Store**

**Play Store 商店素材自動化：**
- `npm run store:graphic`：sharp 自動產生 1024×500 三語 feature graphic
- `npm run store:screenshots`：puppeteer 自動截 1080×2400 多語商店截圖

### 第 31 頁：結論 🔧

本專題成功開發了 HeartBox — 一個結合 AI 情緒分析的加密心情日記與諮商媒合平台，並進一步擴展為**跨平台行動應用**：

- **隱私優先的日記系統**：Fernet 對稱加密，資料庫外洩仍無法讀取日記
- **AI 智慧分析**：自架 TAIDE/LLaVA + LangChain RAG 架構（資料不離境），自動情緒分析、壓力評估、週報摘要
- **完整諮商媒合流程**：諮商師申請、即時通訊（WebSocket）、預約管理、報價系統
- **多元自我照護工具**：心理量表、呼吸冥想、睡眠追蹤、感恩日記、心理健康課程
- **全端工程實踐**：React 19 + Django REST Framework，Cloud Run + Cloudflare Pages
- 🆕 **跨平台原生整合**：Capacitor 包裝 Android App，Health Connect / HealthKit 同步生理數據，**身心一體**的全面健康評估
- 🆕 **生產級 CI/CD**：GitHub Actions 自動化前後端部署 + 行動端 APK 建置
- 🆕 **上架就緒**：Play Store 隱私揭露、健康宣告、商店素材全部備齊
