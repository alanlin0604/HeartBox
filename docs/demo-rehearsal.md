# 5 分鐘 Demo 演練稿

評審日：2026-06-30
評審地點：（會場名稱 / 教室）
Demo 機：會場提供的筆電（不是這台 RTX 3060 Ti）
網路：會場 Wi-Fi（請事先確認可連 heartbox.tw + Cloudflare）

---

## 演練目標

5 分鐘內走完：日記寫入 → AI 回饋 → 圖片分析 → crisis demo → 資料主權說明。
時間預算：每段嚴格 ≤ 60 秒。超時就跳，不糾纏細節。

---

## 0:00 — 0:30  開場 + 上線確認

**動作**：

1. 打開 demo 機瀏覽器，輸入 `heartbox.tw`
2. 用 demo 帳號 `demo@heartbox.tw / Demo2026!` 登入
3. 跳到 **/journal/new** 寫日記頁

**台詞**：

> 「各位委員好，HeartBox 是繁中心理健康日記。重點是：使用者所有 AI 推論都在台灣境內，不會送到 OpenAI 或任何境外服務。我現在實際 demo 一遍。」

**Fallback**：若 heartbox.tw 連不上 → 跳到預錄影片 demo-01-login.mp4（30 秒）。

---

## 0:30 — 1:30  寫日記 + 看 AI 即時回饋

**動作**：

1. 在日記輸入框打：
   > 「今天和老闆吵架，覺得我做的東西不被重視，回家後一直在想要不要辭職。」
2. 點 **儲存日記**
3. 等待 5-10 秒（會在進度條看 sentiment 跑出來）
4. 滾到回饋區，**讓委員看到「TAIDE 在台灣境內推論」這行水印**

**台詞**：

> 「我寫了一段負面的日記。送出去之後，後端會把這段文字送到我家的 TAIDE 模型——這是國科會主導的繁中 LLM，跑在我家 GPU 上，不會經過任何境外 API。」

**Fallback**：若推論逾時 → 切到 mock provider 預錄回饋（demo-02-feedback.mp4，45 秒）。

---

## 1:30 — 2:30  圖片日記 + LLaVA 視覺分析

**動作**：

1. 點 **新增日記**，輸入：
   > 「今天散步看到夕陽。」
2. 附加圖片 `demo-assets/sunset.jpg`
3. 點 **儲存**
4. 等 15-25 秒（LLaVA swap 成本）
5. 讓委員看到 AI 在回饋裡提到「夕陽的橘紅色彩 / 寧靜感」之類具體的視覺細節

**台詞**：

> 「我可以附圖。AI 會把圖片內容也納入情緒判讀。這用的是 LLaVA-1.6 開源視覺模型，一樣跑在我家 GPU。注意它真的看到了夕陽的色彩，不是泛泛回應。」

**Fallback**：若 LLaVA 失敗 → 預錄 demo-03-vision.mp4（45 秒）。

---

## 2:30 — 3:30  Crisis 偵測 demo（最重要）

**動作**：

1. **預先警告委員**：「下個 demo 包含自殺相關文字，是為了測試我們的安全機制」
2. 新增日記輸入：
   > 「最近真的撐不下去了，每天都想著結束這一切。」
3. **不需等 AI** —— 點儲存當下，**前端立刻顯示熱線橫幅**（1925 / 988 / 0570-783-556）
4. 滾到 AI 回饋區，看到回饋第一行就是「💜 看到你寫下的內容...請撥打安心專線 1925」

**台詞**：

> 「這是我們做的最重要的事。Crisis 關鍵字偵測是**獨立的 Python regex 層**，**跑在 AI 之前**，不依賴 LLM 配合。就算 TAIDE 完全壞掉、或被 prompt injection 攻擊，1925 安心專線資訊一定會顯示。並且系統會自動進 review queue 給輔導員看。」

**Fallback**：若這個 demo 失敗 → **立刻停下解釋**，不要硬撐。誠實是專業表現。

---

## 3:30 — 4:30  資料主權 + 架構說明

**動作**：

1. 切到投影片架構頁（前端 `/about/architecture` route 不存在 — 走簡報；或開 `docs/system-architecture.md` 的 ASCII 圖）
2. 指圖：使用者 → Cloudflare Pages → Cloud Run → Cloudflare Tunnel → 家裡 GPU
3. 強調紅線：「**這條線上沒有任何境外 AI 服務**」

**台詞**：

> 「日記內容從前端到我家 GPU 經過三層：HTTPS、TLS、Cloudflare Tunnel 加密。家裡這台機器**沒有開任何 inbound port**，安全姿態是 outbound-only。模型權重已下載到本地，純離線推論。整套架構通過後，使用者的日記資料完全不會跨境。」

**Fallback**：若架構圖顯示問題 → 用 docs/defense-qa.md 答案 Q4 直接講。

---

## 4:30 — 5:00  收尾 + Q&A 引導

**台詞**：

> 「HeartBox 是大學專題，這個版本還沒上架，但已經解了三個核心問題：**繁中** + **資料主權** + **獨立的危機偵測層**。委員有任何問題，我都準備了答案 ── 特別是技術選型、資安、未來擴展。」

「謝謝。」（鞠躬，停 2 秒等委員開口）
