# 健康資訊連動快速指南

## 📱 概述

HeartBox 已經完整實作了健康資料整合功能，支援：
- **iOS：** HealthKit（步數、心率、HRV、卡路里、睡眠）
- **Android：** Health Connect（步數、心率、HRV、卡路里、睡眠）
- **Web/PWA：** 自動降級（不支援健康資料）

## 🚀 快速開始（5 個步驟）

### 第 1 步：安裝健康資料插件（2 分鐘）

```bash
cd frontend

# 安裝健康插件
npm install @capgo/capacitor-health

# 同步到原生專案
npx cap sync
```

**確認安裝：**
```bash
# 檢查 package.json
grep "capacitor-health" package.json
```

應該看到：
```json
"@capgo/capacitor-health": "^8.4.5"
```

---

### 第 2 步：設定 Android Health Connect 權限（3 分鐘）

編輯 `frontend/android/app/src/main/AndroidManifest.xml`，已經有基本配置，確認包含：

```xml
<!-- Health Connect Permissions -->
<uses-permission android:name="android.permission.health.READ_STEPS" />
<uses-permission android:name="android.permission.health.READ_HEART_RATE" />
<uses-permission android:name="android.permission.health.READ_SLEEP" />
<uses-permission android:name="android.permission.health.READ_ACTIVE_CALORIES_BURNED" />

<!-- Health Connect Intent Filter -->
<activity android:name=".MainActivity">
    <intent-filter>
        <action android:name="androidx.health.ACTION_SHOW_PERMISSIONS_RATIONALE" />
    </intent-filter>
</activity>
```

**注意：** Android 14+ 需要 Health Connect，它是 Google Play 服務的一部分。

---

### 第 3 步：設定 iOS HealthKit 權限（3 分鐘）

編輯 `frontend/ios/App/App/Info.plist`（如果不存在，執行 `npx cap sync` 後會生成）：

```xml
<key>NSHealthShareUsageDescription</key>
<string>HeartBox 需要讀取您的健康數據（步數、心率、睡眠），以提供個人化的情緒與健康分析</string>

<key>NSHealthUpdateUsageDescription</key>
<string>HeartBox 需要存取您的健康數據以進行分析</string>
```

**繁體中文版本（建議）：**
```xml
<key>NSHealthShareUsageDescription</key>
<string>HeartBox 需要讀取您的健康資料（步數、心率、睡眠等），以提供個人化的情緒與健康分析。您的健康資料將被加密並僅儲存在您的裝置和私人伺服器中。</string>
```

並且在 `Info.plist` 中加入：
```xml
<key>NSHealthClinicalHealthRecordsShareUsageDescription</key>
<string>HeartBox 不會存取您的臨床健康記錄</string>
```

---

### 第 4 步：建置並測試 Android APP（10 分鐘）

#### 方法 A：使用 Android Studio（本地開發）

```bash
cd frontend

# 1. 建置 Web 並同步到 Android
npm run build:mobile

# 2. 打開 Android Studio
npx cap open android
```

在 Android Studio 中：
1. 連接 Android 手機或啟動模擬器
2. 點擊 "Run" ▶️ 按鈕
3. APP 會自動安裝到手機/模擬器

#### 方法 B：使用命令列（更快）

```bash
# 建置並直接執行
npm run build:mobile
npx cap run android
```

**重要：測試 Health Connect**
1. 確保手機已安裝 **Health Connect** APP（Google Play 下載）
2. 在 Health Connect 中加入一些測試資料（步數、睡眠等）
3. 打開 HeartBox APP
4. 前往「健康資料」頁面
5. 點擊「同步健康資料」
6. 授權 HeartBox 讀取權限
7. 查看是否成功同步資料

---

### 第 5 步：測試健康資料讀取（5 分鐘）

**在 APP 中測試：**

1. **進入健康資料頁面**
   - 打開 HeartBox APP
   - 導航到「健康」或「分析」頁面

2. **請求權限**
   - 點擊「同步健康資料」按鈕
   - APP 會彈出權限請求
   - **Android：** 選擇要分享的健康資料類型
   - **iOS：** 允許讀取 HealthKit 資料

3. **同步資料**
   - 授權後，APP 會自動讀取最近 7 天的健康資料
   - 包括：步數、心率、HRV、卡路里、睡眠時間

4. **查看結果**
   - 健康資料會顯示在圖表中
   - 可以查看每日趨勢
   - 資料會自動上傳到後端（加密儲存）

## 🧪 開發測試流程

### 在真實手機上測試（推薦）

**為什麼要用真機？**
- Android 模擬器預設沒有 Health Connect
- iOS 模擬器的 HealthKit 功能有限
- 真實手機有實際的健康資料

**步驟：**

1. **啟用 USB 偵錯**
   - Android：設定 → 關於手機 → 連點「版本號碼」7 次 → 開發者選項 → USB 偵錯
   - iOS：需要 macOS 和 Xcode（或使用 GitHub Actions 雲端建置）

2. **連接手機到電腦**
   ```bash
   # Android：檢查手機是否連接
   adb devices
   
   # 應該顯示你的手機序號
   ```

3. **執行 APP**
   ```bash
   cd frontend
   npm run build:mobile
   npx cap run android
   ```

4. **在手機上測試**
   - APP 會自動安裝並啟動
   - 測試健康資料同步功能

### 使用瀏覽器 DevTools 除錯

```bash
# Android
chrome://inspect

# 在 Chrome 中打開，可以看到手機上的 WebView
# 點擊 "inspect" 即可使用 Chrome DevTools
```

## 📊 健康資料流程

### 資料流程圖

```
[手機健康 APP]
  ↓
[HealthKit/Health Connect]
  ↓
[@capgo/capacitor-health 插件]
  ↓
[前端 healthKit.js]
  ↓
```

## 🔒 隱私和安全

### 資料加密

HeartBox 對健康資料實施多層加密：

1. **傳輸加密：** HTTPS (TLS 1.3)
2. **儲存加密：** Fernet 對稱加密（後端）
3. **資料庫加密：** PostgreSQL 欄位級加密

### 權限管理

**Android Health Connect：**
- 使用者可以精細控制每種資料類型的權限
- 可以隨時在 Health Connect APP 中撤銷權限
- HeartBox 只讀取，不寫入健康資料

**iOS HealthKit：**
- 遵循 Apple 的隱私指南
- 只請求必要的權限
- 資料不會與第三方分享

### 隱私政策（必須）

**重要：** 上架 App Store / Google Play 前，必須在 APP 中加入隱私政策連結。

在 `frontend/src/pages/SettingsPage.jsx` 中加入：

```jsx
<a href="https://your-domain.com/privacy-policy" target="_blank">
  隱私權政策
</a>
```

並在網站上提供完整的隱私政策，說明：
- 收集哪些健康資料
- 資料如何使用
- 資料如何儲存（加密）
- 資料不會與第三方分享
- 使用者如何刪除資料

## 🐛 常見問題

### Q1: Android 手機沒有 Health Connect？

**解決：**
1. 更新 Google Play 服務到最新版本
2. 從 Google Play 下載 "Health Connect" APP
3. Android 14+ 會預裝 Health Connect

### Q2: iOS 無法讀取 HealthKit 資料？

**檢查：**
1. Info.plist 中是否有 `NSHealthShareUsageDescription`
2. 是否在真實 iPhone 上測試（模擬器功能有限）
3. iPhone 的「健康」APP 中是否有資料

### Q3: 權限請求沒有彈出？

**可能原因：**
1. 之前拒絕了權限（需要去系統設定中手動開啟）
2. 插件未正確安裝（執行 `npx cap sync`）
3. 平台檢測錯誤（確認是在手機而非瀏覽器中執行）

### Q4: 同步後資料沒有顯示？

**除錯步驟：**
1. 打開瀏覽器 DevTools (`chrome://inspect`)
2. 查看 Console 是否有錯誤訊息
3. 檢查 Network 是否成功呼叫 `/api/health/sync/`
4. 查看後端 logs

### Q5: 如何在瀏覽器/PWA 中禁用健康功能？

**已自動處理！** `healthKit.js` 會自動檢測平台：
```javascript
if (platform === 'web') {
  isAvailable = false
  // 健康功能自動禁用
}
```

## 📱 建置完整 APP

### Android APK（測試版）

```bash
cd frontend
npm run build:mobile
cd android
./gradlew assembleDebug

# APK 位置：
# android/app/build/outputs/apk/debug/app-debug.apk
```

### Android AAB（上架 Google Play）

```bash
cd frontend
npm run build:mobile
cd android
./gradlew bundleRelease

# AAB 位置：
# android/app/build/outputs/bundle/release/app-release.aab
```

需要簽名金鑰（參考 [docs/行動裝置APP建置指南.md](docs/行動裝置APP建置指南.md)）

### iOS IPA（需要 macOS 或 GitHub Actions）

因為你沒有 macOS，建議使用 GitHub Actions 雲端建置：

1. 設定 Apple Developer 憑證（.p12）
2. 設定 Provisioning Profile
3. 推送到 GitHub
4. 觸發 "Mobile Build" workflow
5. 下載建置好的 IPA

詳細步驟請參考 [docs/行動裝置APP建置指南.md](docs/行動裝置APP建置指南.md)
