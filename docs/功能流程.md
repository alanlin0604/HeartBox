# HeartBox 心事盒 — 完整功能流程文件

> 給設計師 / cowork：每個功能都列出 **入口 → 步驟 → 分支 → 出口**，按順序可以直接畫流程圖。
>
> 符號慣例：
> - `[人]` = 使用者動作
> - `[統]` = 系統 / 後端自動動作
> - `[3]` = 第三方服務（Google、TAIDE、Open-Meteo、FCM…）
> - `<判>` = 判斷分支
> - `↓` = 順序流動
> - `→` = 分支結果

## 1. 註冊與認證

### 1.1 Email 註冊

**入口**：Landing 頁「免費註冊」按鈕 / 直接訪問 `/register`

```
[人] 進入 /register
   ↓
[人] 填寫 username / email / password / 確認密碼
   ↓
[人] 選擇年齡帶（18+ / 13-17 / under 13）
   ↓
[人] 勾選 4 個同意：服務條款 / 隱私政策 / 13 歲以上聲明 / (選擇)同意 AI 訓練使用
   ↓
[人] 按「註冊」
   ↓
<判> 年齡帶？
   ├─ under 13 → [統] 拒絕（PDPA 法律不允許）→ 顯示「未滿 13 歲無法註冊」
   ├─ 13-17  → [人] 額外填寫家長 email
   │          ↓
   │          [統] 寄信給家長 + 帳號暫時鎖定
   │          ↓
   │          [3 Email] 家長收信 → 點同意連結
   │          ↓
   │          [統] 解鎖帳號
   └─ 18+    → 進入下一步
         ↓
[統] 驗證 username/email 唯一
   ↓
<判> 都唯一？
   ├─ 否 → 顯示錯誤
   └─ 是 → [統] 建立 User（email_verified=False, onboarding_completed=False）
         ↓
         [統] 寄驗證信
         ↓
         [3 Email Office365] 送出驗證 email
         ↓
[人] 收到 email → 點驗證連結
   ↓
[統] 設定 email_verified=True
   ↓
[人] 跳回登入頁
```

### 1.2 Google OAuth 登入

```
[人] 點「以 Google 登入」按鈕
   ↓
[3 Google] 跳出 Google 登入彈窗
   ↓
[人] 選帳號
   ↓
[3 Google] 回傳 credential token
   ↓
[統] POST /api/auth/google/ with credential
   ↓
[統] 驗證 token + 取 Google profile
   ↓
<判> 該 email 是否已有帳號？
   ├─ 是 → 直接登入該帳號
   └─ 否 → 自動建立新帳號（onboarding_completed=False）
         ↓
[統] 發 JWT (access + refresh)
   ↓
[人] 進入主頁
```

### 1.3 一般登入

```
[人] 進入 /login
   ↓
[統] 暖機 ping（背景打 /healthz/，避免冷啟動）
   ↓
[人] 輸入 username / password
   ↓
[人] (選) 勾「記住我」
   ↓
[人] 按「登入」
   ↓
[統] 開計時器 3 秒後顯示 warming-up banner（含秒數計時）
   ↓
[統] POST /api/auth/login/
   ↓
<判> 帳號是否被鎖定（5 次錯誤 → 鎖 15 分鐘）？
   ├─ 是 → 回 423 → 顯示「帳號暫時鎖定」+ 解鎖時間
   └─ 否 → 繼續
         ↓
<判> 帳密正確？
   ├─ 否 → failed_login_count++ → 顯示「登入失敗」
   └─ 是 → 重置 failed_login_count
         ↓
<判> 是否啟用 2FA？
   ├─ 是 → 回傳 partial_token → 跳 2FA 表單
   │       ↓
   │       [人] 開 Google Authenticator 看 6 位數
   │       ↓
   │       [人] 輸入
   │       ↓
   │       [統] POST /api/auth/2fa/login/ with partial_token + code
   │       ↓
   │       <判> TOTP 正確？
   │       ├─ 否 → 顯示錯誤
   │       └─ 是 → 發 JWT
   └─ 否 → 直接發 JWT
         ↓
[統] 回傳 access + refresh token
   ↓
[人] 進入主頁 /
```

### 1.4 忘記密碼

```
[人] 點「忘記密碼？」→ /forgot-password
   ↓
[人] 輸入 email
   ↓
[統] 產生 reset token + 寄信
   ↓
[3 Email] 送出重設密碼信
   ↓
[人] 收信 → 點連結 → /reset-password?token=xxx
   ↓
[人] 輸入新密碼 + 確認
   ↓
[統] 驗證 token + 更新密碼 + 清除所有 refresh tokens
   ↓
[人] 跳回登入頁
```

### 1.5 Token 自動續期

```
[人] 操作任何頁面
   ↓
[統] axios interceptor 攔截 response
   ↓
<判> 是 401 ？
   ├─ 否 → 正常返回
   └─ 是 → 取 refresh_token
         ↓
         <判> refresh_token 還有效？
         ├─ 否 → 清除 token → redirect /login
         └─ 是 → POST /api/auth/refresh/
                ↓
                [統] 回新 access token
                ↓
                [統] 重打原本失敗的請求
```

## 2. 日記功能

### 2.1 寫新日記

**入口**：日誌頁 (/) 上的「撰寫日誌」區塊

```
[人] 進入 / 日誌頁
   ↓
[統] 預載 Daily Prompt + 今日個人化建議（並行）
   ↓
[人] 看到上方有「今日書寫提示」card（可選用）
   ↓
[人] 在 Tiptap 富文本編輯器內寫日記
   ├─ (可) 套用 4 個 quick template (今天感恩的三件事 / 我感謝的人 / 今天的正面時刻 / 我常忽略的美好)
   ├─ (可) 用工具列：粗體、斜體、列表、引用
   └─ (可) 點麥克風 → Web Speech API 語音輸入
   ↓
[人] (可) 選今日活動（運動 / 社交 / 工作 / 閱讀 / 旅行 / 音樂 / 烹飪 / 冥想 / 遊戲 / 購物 / 電影 / 自然）
   ↓
[人] (可) 選天氣（晴 / 多雲 / 雨 / 雪 / 起霧）+ 溫度 (°C)
   ↓
[人] (可) 輸入標籤名稱 → autocomplete 從現有標籤建議 → 沒有就建立新標籤（隨機色）
   ↓
[人] (可) 拖曳或點擊上傳圖片（最大 10MB）
   ↓
[人] 按「儲存日誌」
   ↓
[統] POST /api/notes/
   ↓
[統] 加密內容（Fernet AES-128）+ 計算 search_text（30% 比例）
   ↓
[統] 儲存到 PostgreSQL
   ↓
[統] 立即回應使用者（HTTP 201）→ 樂觀更新前端列表
   ↓
[人] 看到日記出現在下方「最近日記」
   ↓
[統] 背景：開 Thread 執行 _run_full_analysis(note_id)
   │      ↓
   │      [統] 呼叫 LLM Provider
   │      ↓
   │      [3 TAIDE] 推理（5-15 秒）
   │      ↓
   │      [統] 取得 sentiment_score / stress_index / ai_feedback
   │      ↓
   │      <判> 內容含危機關鍵字（自殺/自殘）？
   │      ├─ 是 → 標記 crisis_detected + 推 hotlines
   │      └─ 否 → 繼續
   │      ↓
   │      [統] 更新 MoodNote（加密 ai_feedback）
   │      ↓
   │      [統] 透過 WebSocket 推 'heartbox:note_analyzed' event
   │      ↓
[人] 前端收到 WS event → 自動更新該篇日記顯示情緒分數 + AI 回饋
```

### 2.2 編輯 / 刪除日記

```
[人] 在日記列表右鍵 / 長按 → 跳 context menu
   ↓
[選項 A] 釘選/取消釘選
   ↓
   [統] PATCH /api/notes/{id}/pin/
   ↓
   [人] 看到 📌 圖示

[選項 B] 刪除
   ↓
   [人] 確認 ConfirmModal
   ↓
   [統] DELETE /api/notes/{id}/ → is_deleted=True + deleted_at=now
   ↓
   [人] 從列表移除（軟刪除）
```

### 2.3 垃圾桶 / 還原 / 永久刪除

```
[人] 在日誌頁切到「垃圾桶」tab
   ↓
[統] GET /api/notes/trash/
   ↓
[人] 看到 30 天內被軟刪的日記
   ↓
[選項 A] 還原
   ↓
   [統] POST /api/notes/{id}/restore/ → is_deleted=False
   
[選項 B] 永久刪除
   ↓
   [人] 確認 ConfirmModal（警告無法復原）
   ↓
   [統] DELETE /api/notes/{id}/permanent/ → 真的從 DB 刪除
   ↓
   [統] 級聯刪除附件（GCS 也清掉）

[排程] Celery beat 每天 02:00 跑
   ↓
   [統] 把 deleted_at > 30 天的 row 真的硬刪
```

### 2.4 搜尋與篩選

```
[人] 日誌頁有 SearchFilterPanel
   ↓
[人] 輸入搜尋字串 → 即時打 GET /api/notes/?search=xxx
   ↓
[統] 用 search_text 欄位做 LIKE 比對（前 30% 明文索引）
   ↓
[人] (可) 加入篩選條件：
   ├─ 日期區間（date_from / date_to）
   ├─ 情緒區間（sentiment_min / sentiment_max）
   ├─ 標籤
   ├─ 活動
   ├─ 天氣
   ├─ 有/無 AI 回饋
   └─ 釘選
   ↓
[統] 後端綜合 query → 回傳分頁列表
```

### 2.5 批次刪除

```
[人] 點「選擇模式」
   ↓
[人] 勾選多筆 → 顯示「全選 / 取消」按鈕
   ↓
[人] 點「刪除選取的 N 篇」
   ↓
[人] 確認
   ↓
[統] POST /api/notes/batch-delete/ with ids[]
   ↓
[統] 軟刪除 + 移到垃圾桶
   ↓
[人] toast「已刪除 N 篇」
```

### 2.6 PDF 匯出

```
[人] 點「匯出 PDF」按鈕
   ↓
[人] 選擇要匯出的日記（日期範圍 / 全部）
   ↓
[人] 按確認
   ↓
[統] GET /api/notes/export-pdf/
   ↓
[統] 渲染 HTML 模板 → 用 WeasyPrint 轉 PDF
   ↓
[統] 回傳 PDF blob
   ↓
[人] 瀏覽器自動下載 heartbox-journal-YYYYMMDD.pdf
```

## 3. 每日工具

### 3.1 Daily Prompt（每日書寫提示）

```
[人] 進入日誌頁
   ↓
[統] GET /api/daily-prompt/
   ↓
[統] 檢查 cache (key=daily_prompt_{user_id}_{date})
   ↓
<判> Cache 命中？
   ├─ 是 → 直接回傳
   └─ 否 → 取使用者過去 7 天平均情緒 / 壓力
         ↓
         [統] 呼叫 TAIDE 生成一個 ≤25 字的問句
         ↓
         [3 TAIDE] 推理
         ↓
         <判> 通過 sanitize 驗證（單一問句、長度限制）？
         ├─ 否 → 退回預設模板（30+ 個 prompt 隨機選）
         └─ 是 → cache 12h
         ↓
[人] 看到 prompt card
   ↓
[選項] 「使用此提示」按鈕 → 把 prompt 文字塞進編輯器當開頭
```

### 3.2 今日個人化建議

```
[人] 進入日誌頁
   ↓
[統] 取得使用者地理位置：
   ├─ 讀 localStorage cache（24h TTL）→ 命中直接用
   └─ Cache miss → 跳 navigator.geolocation 授權框（timeout 8s）
         ├─ 授權成功 → 用實際座標，cache 24h
         └─ 拒絕/超時 → 退回台北座標
   ↓
[統] POST /api/personal-suggestion/ with {lat, lon}
   ↓
[統] 檢查 cache (key=user_{id}_{date}_{lat10}_{lon10}_{lang})
   ↓
<判> Cache 命中？
   ├─ 是 → 直接回傳
   └─ 否 → 進入生成流程：
         ↓
         [統] 並行：
         │   ├─ 取 personal_insights（5 維度）
         │   └─ [3 Open-Meteo] GET 今日天氣 + 氣溫
         ↓
         [統] compute_triggers — 計算今天命中哪些條件
         ↓
         <判> 是 zh-TW？
         ├─ 否 → paragraph=None → 前端用模板 tips
         └─ 是 → 呼叫 TAIDE 生成 60-120 字暖心建議
                ↓
                [3 TAIDE] 推理
                ↓
                <判> 長度 20-400 字？
                ├─ 否 → paragraph=None
                └─ 是 → 採用
         ↓
         [統] cache 12h（成功）/ 10 分鐘（失敗）
   ↓
[人] 看到 widget：
   ├─ 標題：「今日個人化建議」
   ├─ 天氣行：「6月29日．晴朗．24°/30°C．目前 27°C」
   ├─ (如有 paragraph) 顯示一段流暢的話
   └─ (沒 paragraph) 顯示 1-4 條模板 tips
```

### 3.3 連續記錄 Streak

```
[人] 寫一篇日記
   ↓
[統] perform_create 觸發 JournalStreak 更新
   ↓
[統] 抓使用者最後一次寫日記的日期
   ↓
<判> 是否為昨天或今天？
   ├─ 今天 → 不變
   ├─ 昨天 → current_streak++
   └─ 更早 → current_streak 重置為 1
   ↓
[統] 更新 longest_streak = max(longest_streak, current_streak)
   ↓
[人] 日誌頁 sidebar 顯示「🔥 連續記錄 X 天」

[排程] Celery beat 每天午夜跑
   ↓
   [統] 對所有「昨天沒寫日記」的 user 重置 current_streak=0
```

## 4. 統計與儀表板

### 4.1 Dashboard 載入流程

```
[人] 點「分析」→「儀表板」/ DashboardPage
   ↓
[統] 並行：
   ├─ GET /api/analytics/?period=week&lookback_days=180
   ├─ GET /api/analytics/calendar/?year=Y&month=M（取當月）
   └─ GET /api/analytics/year-pixels/?year=Y（取今年）
   ↓
[統] /analytics/ 內部 query：
   ├─ get_mood_trends（折線）
   ├─ get_mood_weather_correlation（散布 + 溫度桶）
   ├─ get_frequent_tags（bar chart）
   ├─ get_stress_by_tag
   ├─ get_activity_mood_correlation
   ├─ get_sleep_mood_correlation（如有健康資料）
   ├─ get_personal_insights（5 維度）
   ├─ JournalStreak.current_streak / longest_streak
   └─ Gratitude stats
   ↓
[統] 加上 actual_lookback_days（如資料稀疏會自動擴展到 365）
   ↓
[統] Cache 60 秒（cache_key_v4）
   ↓
[人] 看到 4 區塊：
   ├─ 即時資訊（streak / 本週平均）
   ├─ 趨勢圖表（mood / weather / temperature）
   ├─ 歷史回顧（個人化洞察 / 標籤 / 雷達）
   └─ 行事曆 + 年度像素圖
```

### 4.2 個人化洞察計算

```
[統] get_personal_insights(notes_qs, lookback_days=180) 啟動
   ↓
[統] 5 個維度並行檢查：

[維度 1] 月段 (early/mid/late)
   ↓
   [統] 把日記按月段分組，算每組平均情緒
   ↓
   <判> max - min ≥ 0.3 且每組樣本 ≥ 3？
   ├─ 是 → emit {key: 'month_phase', severity: 'strong/mild'}
   └─ 否 → skip

[維度 2] 平日 vs 週末
   ↓
   <判> 兩組差距 ≥ 0.2？
   ├─ 是 → emit {key: 'weekday_weekend'}
   └─ 否 → skip

[維度 3] 月份極值
   ↓
   <判> 最高/最低月份差 ≥ 0.3？
   ├─ 是 → emit {key: 'month_extremes'}
   └─ 否 → skip

[維度 4] 天氣 (晴 vs 雨)
   ↓
   <判> 兩組差距 ≥ 0.15？
```

## 給設計師的補充提示

1. **顏色語意**：
   - 橘紅色系（HeartBox 品牌色）→ 主動作、強調
   - 灰色 → 中性 / 已讀
   - 綠色 → 成功 / 啟用 / 正向情緒
   - 紅色 → 警示 / 危機 / 停用
   - 黃 / 琥珀色 → 警告 / 中度狀態

2. **狀態指示**：
   - Skeleton loading 用淺灰色 pulse 動畫
   - Cold start 用「正在喚醒伺服器，已等待 X 秒」+ 進度條
   - 成功用 toast（綠色）
   - 失敗用 toast（紅色）

3. **動畫節制**：
   - 不要全頁 fade-in 動畫（易過於花俏）
   - 重要的細微動畫：心情趨勢線繪製、徽章解鎖
   - `prefers-reduced-motion` 必須關掉所有動畫

4. **離線狀態指示**：
   - 網路斷線時 header 顯示淺紅色 banner「目前離線，無法儲存新日記」
   - 重連後自動消失

5. **無障礙**：
   - 所有 icon button 必須有 aria-label
   - 顏色對比 ≥ 4.5:1
   - 表單必須有 label 不能只用 placeholder
